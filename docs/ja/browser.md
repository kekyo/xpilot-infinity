# ブラウザでプレイする

[English](../en/browser.md) · [README に戻る](../../README_ja.md)

WebGL 2 に対応した PC 向けブラウザと、キーボード・マウスを用意してください。
ゲームへの参加には、クライアントのインストールは不要です。

## ゲームに参加する

1. サーバー管理者から案内された URL をブラウザで開きます。自分の PC で下記の npm 版サーバーを起動した場合は `http://localhost:15347/` です。
2. `Ready to join` と表示されたら、`Name` にプレイヤー名を入力し、`Join game` を押します。
3. `Playing` と表示されたら、ゲーム画面をクリックして操作を始めます。
4. 退出するときは `Leave game` を押します。もう一度 `Join game` を押せば再参加できます。

接続先は、そのページを配信しているサーバーです。ブラウザ版にはメタサーバーの一覧やサーバー検索はありません。

## 基本操作

初期設定のキーは次のとおりです。

| 操作 | キー |
| --- | --- |
| 機体を回転 | A / S |
| 推進 | Shift |
| 射撃 | Enter |
| シールド | Space |

チャットは画面下の `Chat` 欄に入力して `Send` を押します。入力後はゲーム画面をクリックして操縦に戻ります。

- `Full screen`: ゲームを全画面表示します。Esc で戻ります。
- `Mouse steering`: マウスで操縦します。Esc でマウスの固定を解除します。
- `Mute`: 効果音を消音します。
- `Save game settings`: ゲーム内で変更した設定を保存します。

プレイヤー名と消音設定は自動で保存されます。保存内容はサイトごとにブラウザへ記録され、次回開いたときに復元されます。
キーが反応しないときはゲーム画面をクリックしてください。

## 自分の PC でサーバーを起動する

Node.js 26.4 以降と npm、配布された `xpilot-infinity-VERSION.tgz` を用意し、アーカイブを保存したディレクトリで実行します。`VERSION` は実際のファイル名に置き換えてください。

```sh
npm install ./xpilot-infinity-VERSION.tgz
npx xpilot-infinity
```

`http://localhost:15347/` を開き、上の手順で参加します。サーバーを終了するには、起動したターミナルで Ctrl+C を押します。
このパッケージにはサーバーとブラウザクライアントが同梱されており、実行時に C コンパイラーや別のネイティブサーバーは必要ありません。

同じネットワークの別の PC からは、`localhost` をサーバーのホスト名または IP アドレスに置き換えます。ブラウザ接続にはサーバーの TCP 15347 番へ到達できる必要があります。

サーバー設定は [Node.js 版の案内（英語）](../../xpilot-server/README.md)、ネイティブ版からの配信や HTTPS 公開は [サーバー公開設定（英語）](../../doc/BROWSER.md) を参照してください。

HTML ファイルを直接開くのではなく、サーバーの `http://` または `https://` の URL を使用してください。
